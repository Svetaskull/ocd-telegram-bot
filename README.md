# Марк — Telegram-бот-комментатор

Марк — Telegram-бот, который автоматически комментирует публикации канала и общается с пользователями в комментариях.

Это учебный Python-проект, постепенно выросший из простого вызова OpenAI API в полноценного Telegram-бота с мультимодальностью и памятью.

## Что умеет Марк

### Комментарии к постам

Марк:

- получает публикации Telegram-канала через связанную группу обсуждений;
- реагирует только на автоматически пересланные публикации канала;
- пишет комментарий в ветке конкретного поста;
- комментирует публикации с вероятностью 70%;
- перед отправкой ждёт случайное время от 20 до 120 секунд.

Это делает его поведение менее механическим.

### Текст

Марк понимает:

- обычные текстовые публикации;
- подписи к фотографиям;
- подписи к видео.

Характер и стиль Марка задаются отдельно в файле:

```text
mark_prompt.txt
```

### Фотографии

Марк умеет анализировать фотографии из Telegram-постов.

При продолжении разговора исходная фотография снова передаётся модели, поэтому Марк может обсуждать детали изображения в следующих сообщениях.

### Видео

Марк умеет анализировать видео.

Из ролика автоматически извлекаются несколько кадров из разных моментов:

```text
10% → 26% → 42% → 58% → 74% → 90%
```

Кадры передаются модели в хронологическом порядке.

Таким образом Марк получает представление о том, что происходило в ролике.

### Распознавание речи

Марк умеет слышать речь из видео.

Схема обработки:

```text
Telegram-видео
        ↓
извлечение аудиодорожки через FFmpeg
        ↓
WAV 16 kHz mono
        ↓
OpenAI Speech-to-Text
        ↓
транскрипция
        ↓
GPT получает текст + кадры + речь
```

Для извлечения аудио используется `imageio-ffmpeg`.

### Кэш видео

Видео не обрабатывается заново при каждом сообщении.

После первого просмотра сохраняются:

- извлечённые кадры;
- транскрипция речи;
- статус транскрипции.

При дальнейшем обсуждении Марк использует локальный кэш.

Если распознавание речи завершилось технической ошибкой, ошибка не считается готовым результатом и при следующей обработке бот попробует снова.

### Диалоги

Пользователь может ответить непосредственно на комментарий Марка.

Марк:

- понимает, на какой свой комментарий получил ответ;
- хранит историю разговора;
- учитывает предыдущие сообщения;
- продолжает разговор, а не начинает его заново;
- поддерживает отдельные ветки диалогов.

### Постоянная память

История разговоров сохраняется локально в:

```text
mark_memory.json
```

Поэтому память не исчезает после перезапуска Python.

Для каждого сообщения Марка сохраняются:

- исходный пост;
- ссылка на исходное фото или видео;
- информация о видеокэше;
- транскрипция;
- история текущей ветки разговора.

Количество сохранённых точек разговора ограничено, чтобы файл памяти не рос бесконечно.

## Установка

Установить зависимости:

```bash
pip install -r requirements.txt
```

`requirements.txt`:

```text
openai
aiogram
opencv-python
imageio-ffmpeg
```

## Переменные окружения

Для работы необходимы две переменные окружения:

```text
OPENAI_API_KEY
TELEGRAM_BOT_TOKEN
```

API-ключи и токены нельзя записывать непосредственно в исходный код или публиковать в GitHub.

Пример для Windows:

```powershell
setx OPENAI_API_KEY "YOUR_OPENAI_API_KEY"
setx TELEGRAM_BOT_TOKEN "YOUR_TELEGRAM_BOT_TOKEN"
```

После изменения переменных окружения необходимо перезапустить терминал или VS Code.
