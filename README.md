# Марк — Telegram-бот-комментатор

Telegram-бот, который автоматически читает публикации канала и генерирует комментарии от лица персонажа Марка с помощью OpenAI API.

Марк — постоянный комментатор канала с характерной манерой общения: сухой юмор, наблюдательность, самоирония и склонность цепляться за мелкие детали публикаций.

Проект создан как практический учебный проект для изучения Python, Telegram Bot API и работы с LLM через API.

## Возможности

- автоматически получает новые публикации Telegram-канала;
- работает как с обычным текстом, так и с подписями к изображениям;
- передаёт содержание публикации в OpenAI API;
- генерирует один комментарий от лица Марка;
- публикует комментарий непосредственно в ветке обсуждения поста;
- использует отдельный системный промпт для настройки характера и стиля персонажа.
